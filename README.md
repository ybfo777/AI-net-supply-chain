# 算力网产业结构互动图

围绕国家"东数西算"工程与新一轮万亿级算力网投资，按 **下游 → 上游** 顺序拆解中国算力网（AI 算力网络）产业链的单文件互动可视化。

## 政策依据（已联网核实，截至 2026-06）

| 政策 | 文号 / 时间 | 关键指标 |
|------|------------|----------|
| 《关于深入实施"东数西算"工程加快构建全国一体化算力网的实施意见》 | 发改委等，构建"算力网"总纲 | 首次以"算力网"统领全国算力一体化 |
| "东数西算"工程 | 2022-02 全面启动（发改委、网信办、工信部、能源局） | 8 大枢纽 + 10 集群；**每年带动投资约 4000 亿元人民币** |
| 《算力基础设施高质量发展行动计划》 | **工信部联通信〔2023〕180 号**（六部门，2023-10） | 2025 年算力 >300 EFLOPS、智算占比 35%、存储 >1800 EB |
| 《算力互联互通行动计划》 | **工信部信管〔2025〕119 号**（工信部，2025-05） | 2028 年基本建成"算力互联网" |

> **关于"几万亿美元"**：官方投资额均以**人民币**计——"东数西算"每年带动约 4000 亿元（≈550 亿美元），
> 多年累计可达万亿元人民币量级；目前并无单一以"万亿美元"计的政策文件，该说法系坊间对累计投资的夸大概括。
> 页面顶部"政策依据"折叠框内附官方原文链接（中国政府网 / 发改委 / 工信部）。

## 直接使用

双击打开 `index.html` 即可（纯静态、零依赖，内嵌全部数据与逻辑）。也可托管到任意静态服务器 / GitHub Pages。

## 产业链分层（从下游到上游）

| 层级 | 名称 | 内容 |
|------|------|------|
| 下游 | 应用与算力服务 | AI 大模型与应用、云计算/算力服务、算力调度与算力网络平台、数据中心/IDC/智算中心 |
| 中游 | 基础设施与设备 | AI 服务器、网络/交换机、光模块、存储设备、散热/液冷、供配电、机电建设 |
| 上游 | 核心芯片与元器件 | AI 芯片/GPU、CPU、存储芯片/HBM、NAND、光芯片、交换芯片、功率芯片、PCB |
| 基石 | 半导体供应链 | 晶圆代工、先进封装/封测、半导体设备（光刻机等）、材料、EDA、IP 核、基础材料 |
| 深层 | 设备核心零部件与高端材料 | 光刻机光源、光学镜头(蔡司)、双工件台、射频电源、真空泵、静电吸盘、大硅片、高端光刻胶、掩膜版、电子特气、CMP 材料、靶材 |
| 底层 | 核心原料与战略资源 | 电子级多晶硅、稀有气体(氖/氪/氙)、稀土、镓/锗、高纯石墨、萤石/氟化工、高纯金属 |

> 后两层从"基石"继续下钻，定位真正最深的卡脖子点（光学镜头、高端光刻胶、大硅片等），
> 同时标出中国手握的"反制筹码"（稀土、镓/锗、石墨、萤石——青色「中国主导」标签）。

## 互动功能

- **点击看详情**：弹出抽屉，展示该环节的产业链定位、代表企业（含 A 股/港股/美股/海外标注）、上下游关联，可一键跳转。
- **悬停高亮上下游**：鼠标悬停任一环节，自动高亮其直接上游（采购自）与下游（供货给），并点亮连线。
- **搜索**：按环节名或企业名（如 `昇腾`、`HBM`、`光模块`、`中芯国际`）实时筛选高亮。
- **筛选**：一键只看"卡脖子"、"国产化突破"或"中国主导/反制"环节。
- **连线**：SVG 贝塞尔曲线表达各环节的供应关系流向。

## 数据说明

节点与企业数据维护在 `index.html` 内的 `NODES` 数组中，结构清晰，便于增删改：

```js
{ id:"gpu", layer:3, name:"AI芯片 / GPU / NPU",
  mini:"...", role:"...",
  companies:[["华为昇腾","PRI"], ...],
  bottleneck:true,        // 卡脖子环节
  up:["eda","foundry", ...] // 上游节点 id，用于连线与高亮
}
```

> 数据为产业结构示意，代表企业列举不构成投资建议；"国产化/卡脖子"标注为公开行业共识的概括。
